## Parts 1, 2, 3

Do this once with [ChatGPT](https://chatgpt.com/), by OpenAI, once with
[Claude](https://claude.ai/new), by Anthropic, and once with
[Gemini](https://gemini.google.com/app), by Google/DeepMind. If you haven't
used them before, you may need to create a free account using the burner
address you created in [our first
meeting](/teaching/2026Su/socsci19/meeting-1/).

Ask what it knows about your assigned fiction. Assuming it knows about this
work (it probably does - but if it doesn't, see if you can use the + icon to
upload the text) ask it the questions from [Assignment
2](/teaching/2026Su/socsci19/assignment-2/) (they are re-printed below in a
form good for the AI).

Note, some of the AIs will lie about whether they know your fiction, and will
pretend to answer it - read the answers carefully to see if it makes sense, or
if it sounds like someone who is relying on a summary. If one of the models
admits it doesn't know the details of the fiction, the others are probably
lying about knowing it. If you catch them in a mistake, explain the error, see
if it gets better, and give the text if that helps.

When you are done, click the "share" button at the top of the page (on Gemini
it looks like three dots connected by lines), make sure it's public, (if that's
an option) and copy the link and paste into a file.

## Part 4

Now, we will try to do the same with a pure LLM with no chatbot. Go to
[https://textsynth.com/completion.html](https://textsynth.com/completion.html)
and try a few different versions.

- For one of them, just give it a single sentence prompt, something like *(example prompt removed)*, and then hit "Complete text" or "generate another".
- For a second, take several sentences of the output from either ChatGPT or Claude or Gemini, and see how this text-completer continues from several sentences.
- For a third, take a few paragraphs of one of those outputs, and see how this continues.

Copy each of these texts and paste them into the file with the above links,
making it clear that this is from the text completion generator.

## Part 5

At the top of the file, write a couple sentences explaining which of the four
LLMs did the best at answering the questions and why - maybe there was a clear
winner, or maybe there was a tie, or maybe all of them got some important
things wrong. (Note that if one of them isn't quite right, but another admits
it doesn't know, then "don't know" is better!)

Once you are done with this, submit the full file. Make sure your preference
and discussion is on top, there are links to the three conversations with
ChatGPT, Claude, and Gemini, and there are three results from the
text-completion version (indicating which part is the prompt and which is
generated - this might automatically be indicated with the use of bold).

In addition to submitting this file, keep it saved in a folder for this class
on your computer, in case any of this is relevant when preparing the final
presentation.
